# Конфигурация каталогов

## Как изменить названия каталогов

Все настройки отображения каталогов находятся в файле `/assets/js/main.js` в объекте `CATALOG_CONFIG`.

### Структура конфигурации

```javascript
const CATALOG_CONFIG = {
  'имя_файла.pdf': {
    title: 'Название каталога',       // Заголовок, отображаемый на карточке
    description: 'Краткое описание',   // Описание (используется для будущих расширений)
    icon: 'ИКО',                       // Текст иконки (2-4 символа)
    color: 'gradient-X'                 // Цветовая схема (gradient-1 до gradient-8)
  }
};
```

### Пример редактирования

Чтобы изменить название каталога HDCNC:

```javascript
'HDCNC华东数控产品综合样本.pdf': {
  title: 'HDCNC',              // ← Измените здесь название
  description: 'Станки с ЧПУ', // ← Измените здесь описание
  icon: 'CN',                   // ← Измените здесь текст иконки
  color: 'gradient-1'           // ← Измените здесь цвет (1-8)
}
```

### Доступные градиенты

- `gradient-1` - Розовый (основной цвет сайта)
- `gradient-2` - Фиолетовый
- `gradient-3` - Красно-розовый
- `gradient-4` - Голубой
- `gradient-5` - Зеленый
- `gradient-6` - Оранжево-желтый
- `gradient-7` - Темно-бирюзовый
- `gradient-8` - Светло-розовый

### Добавление нового каталога

1. Добавьте PDF или XLSX файл в папку `/catalogs/`
2. Добавьте запись в `CATALOG_CONFIG`:

```javascript
'Новый_каталог.pdf': {
  title: 'Мой каталог',
  description: 'Описание',
  icon: 'МК',
  color: 'gradient-1'
}
```

3. Страница автоматически обновится при перезагрузке

### Удаление каталога

1. Удалите файл из папки `/catalogs/`
2. Удалите соответствующую запись из `CATALOG_CONFIG`

## Расположение файлов

- **Конфигурация**: `/assets/js/main.js` (строка ~1325)
- **Стили**: `/assets/css/styles.css` (секция `.pdf-catalogs`)
- **HTML**: `/pages/catalog.html` (секция `<section class="pdf-catalogs">`)
- **Файлы каталогов**: `/catalogs/`

## Адаптивность сетки

Сетка автоматически адаптируется под размер экрана:

- **> 1600px**: 8 колонок
- **1200-1600px**: 6 колонок
- **768-1200px**: 4 колонки
- **480-768px**: 3 колонки
- **< 480px**: 2 колонки
